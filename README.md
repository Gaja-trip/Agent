# 토지정보 통합 안내 페이지

토지이음, 토지이음 지도, 국가법령정보센터를 메인 페이지 안에서 탭으로 연결하고 토지 상담과 토지 정리 절차를 설명하는 공개용 정적 웹페이지입니다.

## 열기

연속지적도 SHP 파일을 함께 불러오기 위해 로컬 서버로 열어야 합니다.

```bash
node server.cjs
```

실행 후 브라우저에서 `http://127.0.0.1:4173/`을 엽니다.

## 구성

- `index.html`: 메인 탭 화면
- `process.html`: 토지 정리 진행 절차
- `checklist.html`: 지적측량 안내자료와 상담 체크리스트
- `manual.html`: 통합 화면 사용 매뉴얼
- `knowledge.html`: 상담지식 요약
- `styles.css`: 반응형 화면 스타일
- `script.js`: 메인 탭, 절차 탭, 안내자료 출력, 체크리스트 상호작용
- `server.cjs`: 정적 파일과 농지공간포털 연동 API를 제공하는 Node 서버
- `farmland-service.cjs`: 농지공간포털 항공영상·연속지적도·공개 필지 속성 조회

## V-World 항공사진

메인 화면의 항공사진 탭은 토지이음 주소검색 값을 V-World 항공사진 위에 표시합니다.
주소를 검색하면 `cadastral` 폴더의 연속지적도 SHP를 읽어 주소 기준 50m 이내 필지 도형을 항공사진에 중첩합니다.

## 항공사진의 도시계획 레이어

항공사진 탭의 **도시계획 레이어**에서 도시계획도로와 기타 기반시설을 각각 켜고 끌 수 있습니다.
V-World 도시계획시설도 WMS의 `lt_c_upisuq151`(도로), `lt_c_upisuq159`(기타 기반시설)를 투명 이미지로 중첩하며, 기본값은 도시계획도로만 표시합니다.
두 레이어의 경계선과 흰색 내부 영역을 붉은 계열로 변환합니다. 원본의 투명도와 명암을 유지하며 선명도를 낮춰도 붉은 색상이 유지됩니다.
버건디 색상의 선명도 조절과 각 레이어의 개별 표시·숨김을 지원하고, 배경지도나 탭을 전환해도 현재 선택을 유지합니다. 기존 편집지적도와 필지 클릭 기능은 독립적으로 동작합니다. 선택 필지 정보는 지번·면적·용도지역·지구만 간결하게 표시하고 패널 간격을 줄여 보기 도구까지 쉽게 접근할 수 있습니다.
배포 도메인의 V-World WMS 이용 권한이 필요하며, 제공 범위와 표시 축척에 따라 데이터가 없는 지역에서는 선이 보이지 않을 수 있습니다.

항공사진의 거리 측정은 지도를 두 지점 이상 클릭한 다음 우클릭 또는 Enter로 완료합니다. 완료된 선과 거리 표시는 남고 다음 클릭부터 별도의 거리를 계속 측정합니다. 왼쪽 패널과 지도 위 거리 표시는 연한 버건디 계열로 표시합니다. ‘초기화’를 누르면 완료된 선을 포함한 모든 측정 결과를 지우고 필지 선택으로 돌아갑니다.

## 농지공간정보

농지공간정보 탭 안에서 공식 포털의 최신 항공영상 WMTS와 연속지적도 WMS를 표시합니다. 포털과 같은 EPSG:5186 좌표계와 타일 격자를 사용합니다.
검색한 지번으로 이동하거나 지도에서 필지를 클릭하면 지목·면적·용도지역·용도지구·토지이용계획·공시지가·건축물정보를 조회합니다. 포함·저촉·접합 관계를 원문대로 표시하며, 조회 실패와 정보 없음을 구분합니다.
항공사진 탭은 V-World 연속지적도에서 PNU를 구하고, `/api/vworld/parcel`을 통해 V-World 국가중점데이터 API `getLandCharacteristics`와 `getLandUseAttr`에서 면적·용도지역·지구를 조회합니다. 농지공간포털 API와 조회 상태·캐시를 분리했습니다. 토지특성의 최신 기준연도·월을 사용하며 포함·저촉·접함 관계를 유지합니다. 면적은 `㎡ (평)` 형식으로 함께 표시하며 평은 ㎡ × 0.3025로 환산해 소수 둘째 자리까지 반올림합니다.
농지공간정보 왼쪽 패널은 필지정보(용도지역·지구와 필지 속성), 토지이용계획, 건축물정보의 세 메뉴로 구분합니다. 토지이용계획 메뉴에서 개별공시지가도 함께 조회합니다. 선택한 메뉴는 필지 조회와 탭 전환 시 유지됩니다.
농지공간정보에서 주소를 검색하면 지도 중앙에 필지를 상세 확대하고 검색 지번을 크게 표시합니다. 연속지적도와 지번 WMS는 검색 위치를 중심으로 반경 100m 안에만 표시하며, 지도 이동·확대·축소에도 기준 위치와 반경을 유지합니다. 같은 주소를 다시 검색하거나 ‘검색한 지번으로 이동’을 누르면 다시 중앙으로 이동합니다.
공식 화면을 iframe으로 삽입하지 않고 공개 영상 및 JSON 속성만 서버를 통해 연동합니다. 숨겨진 소유자·농업인 자료는 전달하지 않습니다.
로컬에서는 Node.js 18 이상에서 `node server.cjs`로 실행합니다. 농지공간포털로의 HTTPS 접근이 필요합니다.
기존 `?portal=realestate` 링크는 농지공간정보 탭으로 연결되며, 항공사진 탭의 지도·클릭 정보 기능은 그대로 유지합니다.

## Vercel 배포

프로젝트 루트 전체를 배포해야 합니다. HTML/CSS/JS만 올리면 농지공간정보 API가 404로 응답합니다.

- `api/farmland/[action].js`가 `/api/farmland/config`, `/info`, `/parcel`, `/tile`, `/wms` 요청을 처리합니다. 로컬과 같은 `farmland-service.cjs`를 사용합니다.
- `api/vworld/parcel.js`는 항공사진용 면적·용도지역·지구를 V-World에서만 조회합니다. 같은 출처의 API를 사용해 브라우저 CORS/JSONP 제한을 피합니다. 서버에서는 `VWORLD_API_KEY`, `VWORLD_API_DOMAIN` 환경변수로 기본 설정을 덮어쓸 수 있습니다.
- `vercel.json`은 정적 화면과 Node API를 함께 배포하도록 설정하며, 함수는 서울(`icn1`)에서 최대 30초 동안 실행됩니다. 별도 npm 패키지나 빌드 작업은 없습니다.
- Vercel 프로젝트 Root Directory는 이 저장소의 루트, Framework Preset은 **Other**를 사용합니다. 저장소 변경을 반영한 **새 배포**가 필요합니다. 이전 소스의 Redeploy만으로 새 파일이 반영되지는 않습니다.
- 배포 후 `/api/farmland/config`가 HTTP 200 JSON을 반환하는지 확인합니다. 지도 화면에서 항공영상·반경 100m 지적도·필지 속성 조회를 확인합니다.
- V-World의 기존 브라우저용 키와 NED API 등록 도메인은 `vworld-config.js`에서 공유합니다. 등록 도메인은 `https://agent-buan.vercel.app`입니다. 키나 서비스 도메인이 바뀌면 V-World 인증센터의 등록 정보와 이 값을 함께 맞춥니다. 서버 API가 없는 정적 환경에서는 브라우저 직접 조회와 JSONP를 시도하며 요청에 시간 제한을 둡니다.
- 로컬 Node에서 `SELF_SIGNED_CERT_IN_CHAIN` 오류가 발생하고 Windows 인증서 저장소에는 신뢰할 수 있는 인증서가 있다면 Node.js 24의 `node --use-system-ca server.cjs`로 실행합니다. 인증서 검증을 끄지 않습니다.

검사: `node --test tests/*.test.cjs`
