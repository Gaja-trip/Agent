# 토지정보 통합 안내 페이지

토지이음, 토지이음 지도, 국가법령정보센터를 메인 페이지 안에서 탭으로 연결하고 토지 상담과 토지 정리 절차를 설명하는 암호 보호 웹페이지입니다.

## 열기

연속지적도 SHP 파일을 함께 불러오기 위해 로컬 서버로 열어야 합니다.

```bash
node server.cjs
```

실행 후 브라우저에서 `http://127.0.0.1:4173/`을 엽니다.

## 비공개 접속

접속 암호는 `jin`입니다. 접속 상태는 8시간 유지되며 상단 자물쇠 버튼으로 다시 잠글 수 있습니다.
페이지뿐 아니라 이미지, 스크립트, 지도 API와 연속지적도 자료도 서버에서 접속 권한을 확인합니다.
HTML 파일 직접 열기나 일반 정적 호스팅에서는 이 보호가 적용되지 않으므로 로컬에서는 `node server.cjs`를 사용합니다.

Vercel 배포에는 `middleware.ts`가 같은 암호 확인을 적용합니다. 변경 사항을 배포해야 기존 공개 주소에도 적용됩니다.
배포 전에 `npm install`로 의존성을 설치합니다. 서버 설정 및 인증 코드는 웹 경로로 제공하지 않습니다.
암호와 세션 서명 키는 서버 환경변수 `SITE_PASSWORD`, `SITE_SESSION_SECRET`으로 변경할 수 있습니다.
암호나 서명 키를 변경하면 기존 접속 쿠키는 무효화됩니다.
배포 보호 방식은 [Vercel Routing Middleware](https://vercel.com/docs/routing-middleware)를 사용합니다.

## 구성

- `index.html`: 메인 탭 화면
- `process.html`: 토지 정리 진행 절차
- `checklist.html`: 지적측량 안내자료와 상담 체크리스트
- `manual.html`: 통합 화면 사용 매뉴얼
- `knowledge.html`: 상담지식 요약
- `styles.css`: 반응형 화면 스타일
- `script.js`: 메인 탭, 절차 탭, 안내자료 출력, 체크리스트 상호작용
- `server.cjs`: 연속지적도 SHP를 함께 제공하는 로컬 정적 서버

## V-World 항공사진

메인 화면의 항공사진 탭은 토지이음 주소검색 값을 V-World 항공사진 위에 표시합니다.
주소를 검색하면 `cadastral` 폴더의 연속지적도 SHP를 읽어 주소 기준 50m 이내 필지 도형을 항공사진에 중첩합니다.
`52800.index.bin`은 50m 주변 도형만 빠르게 찾기 위한 SHP 인덱스입니다.
