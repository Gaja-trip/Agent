# 토지정보 통합 안내 페이지

토지이음, 토지이음 지도, 국가법령정보센터를 메인 페이지 안에서 탭으로 연결하고 토지 상담과 토지 정리 절차를 설명하는 공개용 정적 웹페이지입니다.

## 열기

연속지적도 SHP 파일을 함께 불러오기 위해 로컬 서버로 열어야 합니다.

```bash
node server.cjs
```

실행 후 브라우저에서 `http://127.0.0.1:4173/`을 엽니다.

## 구성

- `index.html`: 메인 탭 화면
- `process.html`: 토지 정리 진행 절차
- `checklist.html`: 지적측량 안내자료와 상담 체크리스트
- `manual.html`: 통합 화면 사용 매뉴얼
- `knowledge.html`: 상담지식 요약
- `styles.css`: 반응형 화면 스타일
- `script.js`: 메인 탭, 절차 탭, 안내자료 출력, 체크리스트 상호작용
- `server.cjs`: 정적 파일과 농지공간포털 연동 API를 제공하는 Node 서버
- `farmland-service.cjs`: 농지공간포털 항공영상·연속지적도·공개 필지 속성 조회

## V-World 항공사진

메인 화면의 항공사진 탭은 토지이음 주소검색 값을 V-World 항공사진 위에 표시합니다.
주소를 검색하면 `cadastral` 폴더의 연속지적도 SHP를 읽어 주소 기준 50m 이내 필지 도형을 항공사진에 중첩합니다.

## 항공사진의 도시계획 레이어

항공사진 탭의 **도시계획 레이어**에서 도시계획도로와 기타 기반시설을 각각 켜고 끌 수 있습니다.
V-World 도시계획시설도 WMS의 `lt_c_upisuq151`(도로), `lt_c_upisuq159`(기타 기반시설)를 투명 이미지로 중첩하며, 기본값은 모두 숨김입니다.
두 레이어의 경계선과 흰색 내부 영역을 붉은 계열로 변환합니다. 원본의 투명도와 명암을 유지하며 선명도를 낮춰도 붉은 색상이 유지됩니다.
선명도 조절과 모두 숨기기를 지원하고, 배경지도나 탭을 전환해도 현재 선택을 유지합니다. 기존 편집지적도와 필지 클릭 기능은 독립적으로 동작합니다.
배포 도메인의 V-World WMS 이용 권한이 필요하며, 제공 범위와 표시 축척에 따라 데이터가 없는 지역에서는 선이 보이지 않을 수 있습니다.

## 농지공간정보

농지공간정보 탭 안에서 공식 포털의 최신 항공영상 WMTS와 연속지적도 WMS를 표시합니다. 포털과 같은 EPSG:5186 좌표계와 타일 격자를 사용합니다.
검색한 지번으로 이동하거나 지도에서 필지를 클릭하면 지목·면적·용도지역·용도지구·토지이용계획·공시지가·건축물정보를 조회합니다. 포함·저촉·접합 관계를 원문대로 표시하며, 조회 실패와 정보 없음을 구분합니다.
항공사진 탭에서도 검색하거나 클릭한 필지의 지번·면적·용도지역·지구를 도시계획 제어 아래 문자로 표시합니다. 면적은 `㎡ (평)` 형식으로 함께 표시하며 평은 ㎡ × 0.3025로 환산해 소수 둘째 자리까지 반올림합니다.
농지공간정보 왼쪽 패널은 필지정보(용도지역·지구와 필지 속성), 토지이용계획·공시지가, 건축물정보의 세 메뉴로 구분합니다. 선택한 메뉴는 필지 조회와 탭 전환 시 유지됩니다.
농지공간정보에서 주소를 검색하면 지도 중앙에 필지를 상세 확대하고 검색 지번을 크게 표시합니다. 연속지적도와 지번 WMS는 검색 위치를 중심으로 반경 100m 안에만 표시하며, 지도 이동·확대·축소에도 기준 위치와 반경을 유지합니다. 같은 주소를 다시 검색하거나 ‘검색한 지번으로 이동’을 누르면 다시 중앙으로 이동합니다.
공식 화면을 iframe으로 삽입하지 않고 공개 영상 및 JSON 속성만 서버를 통해 연동합니다. 숨겨진 소유자·농업인 자료는 전달하지 않습니다.
Node.js 18 이상과 농지공간포털로의 HTTPS 접근이 필요합니다. `node server.cjs`로 실행하며, 배포 시에도 `/api/farmland/*`를 처리하는 서버가 필요합니다. 정적 파일 호스팅만으로는 새 지도 연동이 작동하지 않습니다.
기존 `?portal=realestate` 링크는 농지공간정보 탭으로 연결되며, 항공사진 탭의 지도·클릭 정보 기능은 그대로 유지합니다.
