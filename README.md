# 토지정보 통합 안내 페이지

토지이음, 토지이음 지도, 국가법령정보센터를 메인 페이지 안에서 탭으로 연결하고 토지 상담과 토지 정리 절차를 설명하는 공개용 정적 웹페이지입니다.

## 열기

연속지적도 SHP 파일을 함께 불러오기 위해 로컬 서버로 열어야 합니다.

```bash
node server.cjs
```

실행 후 브라우저에서 `http://127.0.0.1:4173/`을 엽니다.

## 구성

- `index.html`: 메인 탭 화면
- `process.html`: 토지 정리 진행 절차
- `checklist.html`: 지적측량 안내자료와 상담 체크리스트
- `manual.html`: 통합 화면 사용 매뉴얼
- `knowledge.html`: 상담지식 요약
- `styles.css`: 반응형 화면 스타일
- `script.js`: 메인 탭, 절차 탭, 안내자료 출력, 체크리스트 상호작용
- `server.cjs`: 연속지적도 SHP를 함께 제공하는 로컬 정적 서버

## V-World 항공사진

메인 화면의 항공사진 탭은 토지이음 주소검색 값을 V-World 항공사진 위에 표시합니다.
주소를 검색하면 `cadastral` 폴더의 연속지적도 SHP를 읽어 주소 기준 50m 이내 필지 도형을 항공사진에 중첩합니다.

## 항공사진의 도시계획 레이어

항공사진 탭의 **도시계획 레이어**에서 도시계획도로와 기타 기반시설을 각각 켜고 끌 수 있습니다.
V-World 도시계획시설도 WMS의 `lt_c_upisuq151`(도로), `lt_c_upisuq159`(기타 기반시설)를 투명 이미지로 중첩하며, 기본값은 모두 숨김입니다.
두 레이어의 경계선과 흰색 내부 영역을 붉은 계열로 변환합니다. 원본의 투명도와 명암을 유지하며 선명도를 낮춰도 붉은 색상이 유지됩니다.
선명도 조절과 모두 숨기기를 지원하고, 배경지도나 탭을 전환해도 현재 선택을 유지합니다. 기존 편집지적도와 필지 클릭 기능은 독립적으로 동작합니다.
배포 도메인의 V-World WMS 이용 권한이 필요하며, 제공 범위와 표시 축척에 따라 데이터가 없는 지역에서는 선이 보이지 않을 수 있습니다.

## 농지공간정보

농지공간정보 탭에서 농지공간포털 공식 지도(`https://njy.mafra.go.kr/map/mapMain.do#n`)를 새 창으로 엽니다.
공식 지도에서 일반지도·항공영상 전환과 필지정보 선택 후 필지 클릭에 따른 속성 조회를 이용합니다.
검색 주소는 주소 복사 버튼으로 복사한 뒤 공식 지도에서 검색합니다. 자동 위치 연동은 지원하지 않습니다.
공식 서비스의 `X-Frame-Options: SAMEORIGIN` 정책으로 지도 자체를 이 사이트 내부에 삽입할 수 없습니다.
기존 `?portal=realestate` 링크는 농지공간정보 탭으로 연결되며, 항공사진 탭의 지도·클릭 정보 기능은 그대로 유지합니다.
