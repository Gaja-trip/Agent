    로드뷰 멀티뷰

    같은 위치의 서로 다른 촬영 시기를 같은 방향에서 비교하는 도구입니다. 화면 위에서 촬영일을 선택하세요. 어느 화면을 회전하거나 확대해도 다른 화면의 시선이 함께 맞춰집니다. 바닥 화살표로 이동하면 이동한 위치의 촬영 기록을 다시 확인합니다.

    위치마다 제공되는 촬영일과 기록 수가 다릅니다. 이동 시 직접 선택한 날짜에 가장 가까운 촬영 기록을 표시하며, 실제 촬영일은 각 화면에 표시됩니다. 과거 영상은 촬영 차량의 위치 차이로 구도가 조금 다를 수 있습니다.

    API 키 없이 카카오의 공개 로드뷰 뷰어를 불러옵니다. 공식 지원 SDK 연동이 아니므로 카카오 측 변경에 따라 작동이 달라질 수 있습니다. 사진과 지도 데이터의 권리는 Kakao에 있습니다.

    왼쪽의 주소 검색에서 도로명·지번 주소를 검색하고 결과를 선택하면 좌표로 변환한 뒤 주변 로드뷰로 이동합니다. 주소 좌표와 실제 촬영 지점은 다를 수 있습니다. 주소 검색도 카카오의 공개 웹 인터페이스를 사용하며 제공자 변경에 영향을 받을 수 있습니다.

    URL의 lat(위도), lng(경도)로 시작 위치를 지정할 수 있습니다. pan, tilt, zoom은 시선 방향과 확대 수준입니다.
